# Урок 8: Auth на сервере

Критерий: **5**

Docs: [Authentication](https://nextjs.org/docs/app/guides/authentication)

Роли: Юра пишет код урока руками. Чат — подходы и маленький пример. Агент — только согласованная рутина. Полных исходников здесь нет; примеры — в чате на уроке.

## В продукте

Логин в кабинет: Server Action; сессия — httpOnly cookie + user id; пароль в env. Проверка в Action **и** в RSC кабинета. Middleware — только редирект неавторизованного, не граница безопасности. Гостевые `/` и `/menu` без сессии. Один учебный пользователь, без ролей сети и ACL на блюда.

## Подходы

**A.** Cookie httpOnly, проверка на сервере в двух местах (страница + мутация). Скрыть кнопку «изменить цену» — только UX. Middleware не доверяем как единственной защите.

**B.** NextAuth / Auth.js сразу. Провайдеры съедают урок «не доверяй клиенту». Библиотека cookie — открытый вопрос стека, не решение: пока пишем сами.

**Не SPA-привычка.** Не `if (user) showEdit` на клиенте, не `?admin=1`, не `role` в теле запроса. `'use client'` не граница безопасности.

## Зафиксировано

[decisions.md](../decisions.md), 2026-10-12: логин — Server Action; Route Handler — контраст (не основной логин); httpOnly cookie + user id; пароль в env; проверка в Action и RSC; middleware только редирект; без NextAuth / ORM. Не переоткрываем. Хост и путь SQLite на деплое — не этот урок.

## Кто пишет

- **Юра:** login Action (set cookie); logout; чтение сессии в RSC кабинета и в update-Action; отказ в мутации без cookie даже если UI обойти; middleware-редирект с маршрута кабинета на логин (путь кабинета в уроке, не заранее).
- **Агенту позже, если явно «это делаешь ты»:** `.env.example` без секрета; не выбирать NextAuth «заодно».

## Проверка

Без cookie: страница кабинета не отдаёт данные, Action UPDATE не проходит (прямой POST тоже). С cookie: цена меняется, `revalidateTag` как в уроке 7. Гость `/menu` без логина. Снять middleware — проверка в Action всё ещё держит запись. Повесить только middleware без проверки в Action — дыра; так и формулируем.

## Фразы на интервью

1. «Скрыть UI недостаточно: права проверяю в Server Action и в RSC.»
2. «`'use client'` не граница безопасности; cookie httpOnly, не флаг в React-стейте.»
3. «Middleware редиректит гостя с кабинета; это UX, не авторизация мутации.»
