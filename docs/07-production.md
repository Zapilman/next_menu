## Рекомендуемый дефолт

**Сборка:** `next build` + `next start`. Смотреть: какие маршруты static, какие dynamic; размер клиентских чанков каталога vs кабинета.

**Ключевые сценарии:**

1. Гость открыл QR / URL заведения — HTML меню без логина, SEO-metadata на месте
2. Гость перешёл в раздел (если маршрут есть) — клиентская навигация, без полной перезагрузки
3. (Позже) Персонал: логин → правка цены → гость после revalidate видит новую цену. Без пункта 3 критерий 4/5 в проде не закрыт

**Деплой:** Vercel — дефолт для App Router (статика, ISR, serverless). Для JSON в репозитории этого достаточно. Свой Node — если нужен постоянный SQLite-файл.

**Измерения (связка с критерием 7):** сравнивать `next dev` и prod: Full Route Cache виден в build output, не в dev. Bundle analyzer — отдельный урок, не в CI сразу.

**Секреты:** пароль кабинета только в env. Не коммитить. Локально — `.env.example` с пустым значением.

## Альтернативы

| Тема | Вариант | Заметка |
|------|---------|---------|
| Хост | Vercel | Проще ISR, ephemeral FS — SQLite на запись плох |
| Хост | Node на VPS / Docker | Честный файл БД, сами сертифицируем cache |
| Данные | JSON в git | Деплой = контент; мутации на хосте нет |
| Данные | SQLite volume | Нужен хост с диском |
| CI | Только локальный `next build` | Нормально для учёбы |
| CI | GitHub Action на build | Имеет смысл, когда появится код |

Не тащить: Kubernetes, CDN вручную, preview-провайдеры сверх хоста, мониторинг APM.

## Компромиссы

- Vercel + JSON: идеально для уроков 1–3 и 7–8, слабо для записи в кабинете.
- Vercel + SQLite: запись теряется между инстансами — плохой урок про данные, если не оговорить.
- Docker + SQLite: честнее прод для кабинета, больше ops, чем нужно Юре.
- Проверять только в `next dev`: провал критерия 8 — кэш и бандлы другие.

## Зафиксировано (см. [decisions.md](./decisions.md))

- Проверка прода: `next build` + `next start` локально
- Vercel — опционально, публичное меню read-only (SQLite копируется на билде)
- Запись из кабинета — только локальный `next start`, не Vercel FS
- Docker / `standalone` / CI — не в первом срезе
- Bundle analyzer — урок 6
- Сценарии: гость `/` и `/menu`; `Link` в раздел; позже логин → цена → revalidate
- Пароль кабинета в env, `.env.example` без секрета
