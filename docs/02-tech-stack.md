# Стек

Узкий стек. Библиотека — только если без неё нельзя закрыть критерий. Не «привычный набор».

## Что решить до кода

- Tailwind vs CSS Modules
- Источник данных: mock JSON vs SQLite
- Нужны ли auth-библиотека, клиентский кэш, глобальный store в первом срезе
- Версия Next.js: стабильный App Router, без экспериментальных API как фундамента

## Рекомендуемый дефолт

Берём сразу:

- Next.js (App Router)
- React
- TypeScript

Не берём в первом срезе:

- NextAuth / Auth.js — критерий 5 закрывается проверкой сессии на сервере; библиотека не обязательна
- Zustand — нет сложного клиентского состояния; каталог живёт на сервере
- React Query — это модель SPA. Позже один урок-контраст: клиентский каталог с React Query vs RSC + cache
- UI-киты, ORM, tRPC, Redux, Axios, form-библиотеки

Стиль и данные — открыты, но дефолт-кандидаты:

- Стиль: CSS Modules, если цель — не учить Tailwind. Tailwind — если хотим быстрее верстать учебный UI без дизайн-системы.
- Данные: mock JSON в репозитории. Хватает для RSC-чтения, Full Route Cache и «прямого доступа без API». SQLite — когда понадобится мутация в кабинете без выдуманного write-JSON.

## Альтернативы

| Тема | Вариант | Когда имеет смысл |
|------|---------|-------------------|
| Стиль | Tailwind | Быстрый учебный UI, утилиты |
| Стиль | CSS Modules | Явная граница стилей, без ещё одного DSL |
| Данные | JSON | Нулевой ops, легко читать в RSC |
| Данные | SQLite (`better-sqlite3` или драйвер) | Кабинет с UPDATE, один файл БД |
| Данные | Postgres | Избыточно для одного заведения |
| Auth | Подписанная cookie вручную | Минимум зависимостей, больше кода урока |
| Auth | Auth.js | Когда урок именно про провайдеров |
| Клиентские данные | React Query | Урок «почему SPA кэширует иначе» |
| State | Zustand | Только если кабинет станет толстым клиентом |

## Компромиссы

- JSON проще для критериев 1–3 и 7, слабее для 4–5 (негде честно писать).
- SQLite честнее для Actions, добавляет драйвер — уже «лишняя» библиотека, оправданная критерием 4.
- Tailwind ускоряет UI, но не является критерием. CSS Modules не спорят с RSC.
- React Query в фундаменте вернёт проект в знакомый SPA и спрячет Data/Full Route Cache.
- NextAuth в фундаменте смещает фокус с «не доверяй клиенту» на настройку провайдера.

## Зафиксировано (см. [decisions.md](./decisions.md))

- CSS Modules, без Tailwind
- SQLite сразу (не JSON-моки)
- Кабинет не в первом срезе
- Ядро: App Router + React + TypeScript; без NextAuth / Zustand / React Query / UI-кита

## Открытые вопросы стека

- React Query: какой урок и на какой фиче, чтобы это был контраст, а не замена RSC (категория «уроки»)
- Одна маленькая lib для cookie/session, когда дойдём до кабинета
- SQLite-драйвер: `@libsql/client` (2026-10-13; `better-sqlite3` не собрался на этой машине)
